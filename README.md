# نظام المحل — نسخة تجريبية (مثال)

هاد المستودع فيه **نسخة تجريبية** ديال نظام المخزون والبحث ديال المحل (العبايات، الخمارات، النقاب...).

- الواجهة نفسها ديال النظام الحقيقي، ولكن البيانات كتبقى غير فالمتصفح (localStorage).
- النظام الحقيقي كيخدم بـ **PHP + MySQL (XAMPP)** فحاسوب المحل، والبحث بالصورة فيه بنموذج **CLIP** (transformers.js).
- كود السيرفر (PHP) كاين فالمجلد `source/`، وكيبان حتى من الزر «كود السيرفر» فالصفحة.

> هاد النظام غير مثال، ماشي نسخة نهائية. ما نقلناش من النظام الأول (v1): تكتب من الصفر.

## التشغيل محلياً
حل `index.html` من أي سيرفر ستاتيكي (مثلاً XAMPP: حط المجلد فـ `htdocs`).
