# نظام المحل — نسخة تجريبية (مثال)

يحتوي هذا المستودع على **نسخة تجريبية** من نظام المخزون والبحث الخاص بالمحل (العبايات، الخمارات، النقاب...).

- الواجهة نفسها الخاصة بالنظام الحقيقي، لكن البيانات تُحفظ في المتصفح فقط (localStorage).
- يعمل النظام الحقيقي بـ **PHP + MySQL (XAMPP)** على حاسوب المحل، ويعتمد البحث بالصورة على نموذج **CLIP** (transformers.js).
- شيفرة الخادم (PHP) موجودة في المجلد `source/`، وتظهر أيضًا عبر زر «شيفرة الخادم» في الصفحة.

> هذا النظام مجرد مثال، وليس نسخة نهائية.

## التشغيل محليًا
افتح `index.html` عبر أي خادم ملفات ثابتة (مثلًا XAMPP: ضع المجلد داخل `htdocs`).
